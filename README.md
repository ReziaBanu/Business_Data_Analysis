# Business Data Analysis Using Linear Algebra, Probability, and Statistics

## 📌 Project Overview

This project focuses on applying mathematical and statistical techniques to analyze business data and identify meaningful patterns, relationships, and probabilities.

The objective is to develop a Python-based analysis solution using **Linear Algebra, Probability, and Descriptive Statistics**. These techniques help understand business data and support informed decision-making before applying advanced predictive models.

The project is implemented using Python libraries such as NumPy, Pandas, SciPy, and Statistics in Google Colab / Jupyter Notebook / VS Code.

## 🎯 Objectives

- Perform mathematical operations using Linear Algebra concepts.
- Understand and calculate probabilities related to business scenarios.
- Apply conditional probability and Bayes' theorem.
- Simulate binomial, normal, and uniform distributions.
- Calculate descriptive statistical measures.
- Interpret data distribution using skewness and kurtosis.

## 🛠️ Technologies and Libraries Used

- **Python** – Programming language

- **SciPy** – Statistical calculations and probability distributions

## 📊 Tasks Performed

### Task 1 – Linear Algebra Implementation

Using NumPy, various linear algebra operations are performed on predefined vectors and matrices.

**Activities:**

- Vector Addition
- Vector Subtraction
- Vector Dot Product
- Matrix Addition
- Matrix Multiplication
- Determinant Calculation
- Inverse of a Matrix (if determinant is non-zero)
- Eigenvalues and Eigenvectors Calculation

**Libraries Used:** NumPy

### Task 2 – Probability Concepts

Probability concepts are applied to understand customer purchasing behavior and business sales outcomes.

**Activities:**

1. **Probability of Successful Sales**
   - Calculate the probability of successful and unsuccessful sales.

2. **Conditional Probability**
   - Analyze purchase probabilities for Premium and Regular customer segments.

3. **Bayes' Theorem**
   - Calculate the updated probability of a customer being Premium given that the customer makes a purchase.

4. **Binomial Distribution**
   - Simulate a binomial distribution using 20 trials with a success probability of 0.65.

5. **Normal Distribution**
   - Generate a normal distribution using:
     - Mean = 50
     - Standard Deviation = 10

6. **Uniform Distribution**
   - Generate a uniform distribution using:
     - Lower Limit = 0
     - Upper Limit = 1

**Libraries Used:** NumPy, SciPy, Python

### Task 3 – Descriptive Statistics

Descriptive statistical techniques are used to understand the distribution and characteristics of sales data.

**Activities:**

- Calculate Mean
- Calculate Median
- Calculate Mode
- Calculate Range
- Calculate Variance
- Calculate Standard Deviation
- Measure Skewness
- Measure Kurtosis
- Interpret the distribution as symmetric, positively skewed, or negatively skewed.

**Libraries Used:** NumPy, Pandas, SciPy, Statistics
